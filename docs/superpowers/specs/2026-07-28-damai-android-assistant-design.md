# 大麦 Android 抢票助手基础版设计

## 1. 目标

构建一个可直接安装的 Android APK，先在普通 Android 模拟器上开发和验证，再在华为 Mate 30 Pro + HarmonyOS 5.0 上做兼容性验证。助手服务于单个大麦账号、单台设备和单个预约任务，操作范围限于大麦官方 App 的可见界面。

首版覆盖以下流程：用户提前登录并配置预约任务，助手在开售时间识别目标页面，自动选择用户指定的票档、数量和观演人，遇到验证码、滑块或其他人机校验时暂停并通知用户，人工处理后继续，进入付款页面后立即停止自动操作。

## 2. 非目标

- 不自动输入支付密码、短信验证码或其他支付凭证。
- 不识别、绕过或代答验证码、滑块、人机校验。
- 不绕过大麦的排队、库存、设备风控或账号限制。
- 不调用大麦未公开接口，不抓取隐藏库存数据。
- 不支持多账号、多设备、远程设备、模拟器批量控制或服务器调度。
- 不保存大麦账号密码、支付信息或完整身份证号码。
- 首版不实现 OCR；保留页面读取扩展点，只有在无障碍树无法满足实际测试时再单独评估。

## 3. 目标运行环境

### 3.1 开发与验证环境

- 第一阶段：普通 Android 模拟器，验证 APK、任务、权限、无障碍页面读取和人工接管逻辑。
- 第二阶段：华为 Mate 30 Pro + HarmonyOS 5.0，验证华为系统权限、后台运行和大麦页面实际兼容性。

用户已确认目标华为设备可以安装运行 APK，并可以运行大麦 App，但仍需实机验证无障碍服务是否能读取和操作大麦页面。

### 3.2 APK 分发

- 采用签名 APK 文件直接安装。
- 首版不接入应用商店、不做账号系统、不依赖云端服务。
- 发布版本需要固定签名，后续升级沿用同一签名。

## 4. 用户流程

### 4.1 首次启动

1. 助手读取设备型号和系统版本。
2. 检查无障碍服务、通知、悬浮窗、前台服务以及华为系统的自启动和后台运行能力。
3. 缺少必需能力时显示缺失项和系统设置入口。
4. 所有必需能力满足前，不允许创建或启动抢票任务。
5. 用户确认助手只操作可见页面，不保存账号密码和支付信息。

### 4.2 创建任务

任务仅包含一个活动、一个场次和一个票数配置。用户在大麦 App 中手动登录并打开目标活动页面后，可执行“读取票档”。助手读取当前可见票档，展示名称、价格和当前状态，用户设置主选和备用票档优先级。

如果预约阶段没有显示票档，用户可以手动填写票档名称和价格；开售时助手仍需重新读取页面并确认票档当前可见且可选。

用户同时选择具体观演人。选择人数必须与购票数量一致，例如购买 2 张票时必须提前指定 2 位观演人。助手不根据页面顺序随机选择观演人。

### 4.3 执行任务

1. 任务进入“等待开售”状态。
2. 开售前由前台服务保持任务运行，并展示状态通知。
3. 到达设定时间后，助手监听大麦页面变化并重新读取当前可见信息。
4. 助手按票档优先级匹配“名称 + 价格 + 可选状态”。
5. 助手选择用户预设的票档、数量和观演人。
6. 页面出现验证码、滑块、短信验证、登录失效或不明确的异常状态时，任务暂停并通知用户。
7. 用户完成允许的人工操作后，通过悬浮控件或通知恢复任务。
8. 识别到订单确认页或付款页后，停止所有自动点击，并通知用户接管。

## 5. 系统架构

首版采用本地单体 APK，按职责划分以下模块：

| 模块 | 职责 |
|---|---|
| `MainActivity` | 展示任务列表、权限状态和任务编辑界面 |
| `PermissionCoordinator` | 检查系统权限，提供设置页跳转和最终可用性判断 |
| `TaskRepository` | 在应用私有存储中保存和读取单个任务配置，不保存账号密码或支付数据 |
| `TaskScheduler` | 根据开售时间启动或唤醒任务，负责时间状态，不直接执行页面点击 |
| `DamaiAccessibilityService` | 监听大麦前台窗口和页面变化，读取可见控件并执行受控操作 |
| `PageReader` | 将无障碍节点树转换为标准化页面状态；首版实现 Accessibility 读取器 |
| `TicketMatcher` | 根据票档名称、价格和状态匹配任务配置 |
| `ViewerSelector` | 根据用户指定的观演人集合勾选页面中的对应人员 |
| `PurchaseStateMachine` | 管理预约、等待开售、选票、人工接管、付款页停止等状态转换 |
| `HumanHandoffNotifier` | 通过通知和悬浮控件提示用户处理异常或付款 |
| `LocalEventLog` | 记录任务状态和错误类型，不记录账号密码、身份证号码或支付信息 |

模块之间通过明确的数据对象传递状态，不让页面识别模块直接修改任务配置，也不让通知模块直接执行大麦点击。

## 6. 页面读取与操作

### 6.1 无障碍读取

`DamaiAccessibilityService` 监听窗口状态变化、内容变化和可交互控件变化。`PageReader` 遍历 `AccessibilityNodeInfo`，读取可见文本、内容描述、控件类型、可点击状态、启用状态、屏幕边界和父子层级。

票档读取按父容器聚合信息：在同一票档容器中组合名称、价格和状态，生成标准化票档对象。价格统一转换为整数分或整数元，清理空格、换行和货币符号；状态识别至少覆盖可选、售罄、缺货、不可用和加载中。

点击优先使用控件自身的 `ACTION_CLICK`。只有在控件明确可点击、边界有效且页面状态与任务匹配时，才允许使用控件边界内的辅助点击。无法确认目标时暂停，不按固定屏幕坐标盲点。

### 6.2 票档匹配

开售时重新读取当前页面，按以下顺序处理：

1. 过滤名称和价格都匹配的票档。
2. 过滤不可选、售罄和加载中的票档。
3. 按用户配置的优先级选择第一个可用票档。
4. 主选和备用都不可用时暂停并通知用户。
5. 页面信息冲突或存在多个无法区分的候选时暂停，不自动猜测。

### 6.3 观演人匹配

用户提前在大麦官方 App 中维护观演人，助手任务只保存用户选中的展示名称或本地任务标识。运行时匹配页面可见的观演人列表并勾选指定人员。

如果指定观演人缺失、存在同名且无法确认、选择数量与票数不一致，任务进入人工接管状态。助手不自动创建新观演人，也不保存身份证号码。

## 7. 状态机

首版状态如下：

```text
未配置
  -> 待权限
  -> 已配置
  -> 等待开售
  -> 页面准备
  -> 读取票档
  -> 选择票档
  -> 选择数量
  -> 选择观演人
  -> 提交订单
  -> 付款页已停止
```

以下事件统一转入 `人工接管`：

- 验证码或滑块出现；
- 短信验证出现；
- 登录失效；
- 排队状态无法确认；
- 票档或观演人匹配不明确；
- 无障碍服务关闭；
- 页面连续变化但无法识别；
- 发生异常或进入未知页面。

人工接管恢复后，状态机重新读取页面，不复用过期的节点引用。

以下事件统一转入终止状态：

- 识别到付款页；
- 用户主动停止；
- 任务超时；
- 关键权限被撤销；
- 发生不可恢复错误。

## 8. 权限与安全

首版将无障碍服务、通知权限、悬浮窗能力和前台运行能力全部设为任务运行的必需条件。华为系统提供的自启动、后台运行和电池策略也必须满足；缺少任一关键能力时，应用禁止创建或启动抢票任务。前台服务本身通过 Android 服务机制维持，应用会在启动任务前验证服务是否成功运行。

应用只使用应用私有目录保存任务配置和本地日志。日志只记录状态名、时间、错误类型和是否进入人工接管，不记录页面截图、身份证号码、账号密码、短信验证码或支付内容。

## 9. 错误处理

| 错误 | 处理方式 |
|---|---|
| 权限缺失 | 禁止启动任务并提供设置入口 |
| 无障碍服务被关闭 | 立即停止自动操作并通知 |
| 大麦不在前台 | 暂停并提示用户返回大麦 |
| 票档读取为空 | 等待页面稳定后重读；仍为空则人工接管 |
| 票档匹配冲突 | 不点击，提示用户确认 |
| 观演人缺失 | 不创建新人员，转人工接管 |
| 页面结构变化 | 记录错误并停止，不执行盲点 |
| 验证码/滑块 | 暂停并提醒用户 |
| 付款页 | 停止所有自动化并通知用户 |
| 任务超时 | 停止服务并保存结束原因 |

## 10. 测试策略

### 10.1 模拟器测试

- APK 安装、启动和升级；
- 权限检测和设置入口；
- 单任务创建、编辑、删除和持久化；
- 时间状态转换；
- 模拟页面节点树中的票档解析、状态识别和优先级匹配；
- 4 个观演人中固定选择 2 人的数量校验；
- 人工接管、恢复和付款页停止；
- 无障碍服务关闭、页面未知和任务超时等错误路径。

### 10.2 真实华为环境测试

在华为 Mate 30 Pro + HarmonyOS 5.0 上验证：

- APK 是否能正常安装和升级；
- 无障碍服务是否能开启并保持运行；
- 前台服务、自启动、电池策略和悬浮窗是否需要额外系统设置；
- 大麦页面是否能暴露可读控件；
- 票档和观演人是否能正确读取和选择；
- 验证码人工接管后能否恢复；
- 付款页是否能可靠停止自动操作。

模拟器通过不代表华为真机兼容，真机验证是发布前的必要条件。

## 11. 验收标准

基础版只有在以下条件全部满足时才视为可交付：

1. APK 可以在目标开发模拟器中安装并启动。
2. 权限不完整时不能启动任务。
3. 任务配置可以保存并恢复。
4. 票档读取结果可以展示名称、价格和状态。
5. 票档优先级匹配结果可预测，未配置的票档不会被自动选择。
6. 购票数量与观演人数量不匹配时不能启动。
7. 指定观演人缺失或无法确认时会暂停。
8. 验证码和滑块出现时会暂停并提醒人工操作。
9. 人工处理后可以从当前页面重新读取并继续。
10. 识别到付款页面后不再执行任何自动点击。
11. 日志不包含账号密码、身份证号码、短信验证码或支付信息。
12. 在华为 Mate 30 Pro + HarmonyOS 5.0 上完成至少一轮实际兼容性验证，或明确记录尚未验证的限制。
