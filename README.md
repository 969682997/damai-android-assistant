# 大麦 Android 助手基础版

这是一个面向单账号、单台 Android 设备的旁加载 APK 原型。它通过 Android 无障碍服务读取大麦官方 App 的可见页面，并按用户预先配置的任务辅助选择票档和观演人。

## 明确边界

- 只支持一个本地任务、一个账号和一台设备。
- 观演人必须提前在大麦中维护，任务中选择具体姓名；购票数量必须和观演人数一致。
- 票档使用“名称 + 价格 + 主选/备用优先级”匹配，页面显示售罄、歧义或缺失时不盲点。
- 遇到验证码、滑块、短信验证、排队、登录失效或未知页面时暂停，交给用户处理。
- 识别到付款、收银台或支付订单页面后停止自动动作。
- 不读取、不保存支付密码、短信验证码、身份证号码或页面截图，不调用大麦未公开接口，也不绕过人机校验、排队或风控。

## 安装和首次使用

1. 构建 `app/build/outputs/apk/debug/app-debug.apk` 后，将 APK 旁加载到模拟器或 Android 手机。
2. 在“权限设置”中开启“大麦助手页面辅助服务”、悬浮窗、通知和精确定时权限。
3. 打开“编辑预约任务”，按以下格式保存：
   - 开售时间：Unix 毫秒时间戳；
   - 观演人：多个姓名用英文逗号分隔；
   - 票档：每行 `名称|价格元|优先级`，优先级数字越小越优先。
4. 先打开大麦并登录，再返回助手点击“开始任务”。
5. 用户自行处理验证码、滑块、短信验证和支付；付款页出现后助手不再继续点击。

## 构建和测试

在已安装 Android SDK、Java 17 的环境中运行：

```text
gradlew.bat testDebugUnitTest
gradlew.bat assembleDebug
```

首版 APK 仅用于模拟器和受控测试。模拟器不能代表华为 Mate 30 Pro + HarmonyOS 5 的无障碍、后台保活和大麦页面兼容性，真机验证仍需单独进行。
